# x265-butler has moved

This repository is archived. x265-butler lives on GitLab now:

**https://gitlab.com/MisterJB/x265-butler**

- Source, issues, merge requests and release notes: on GitLab.
- Docker image: `registry.gitlab.com/misterjb/x265-butler:latest`
- Existing unRAID installs: edit the container and change the Repository field to
  `registry.gitlab.com/misterjb/x265-butler:latest`, otherwise you stay on 2.53.0 and receive no
  further updates. The old `ghcr.io` image is no longer updated.
- Help with setup and usage: the [unRAID forum thread](https://forums.unraid.net/topic/182094-support-human-126094-docker-templates/).

The ffmpeg mirror releases of this repository stay available for the source notices of images up to
2.53.0; the same files are also on the GitLab releases page.
